# Vito Lin (vito-lin-dev)

AI Infrastructure Engineer based in Taipei, Taiwan.

I build and operate on-prem GPU platforms for LLM inference on Kubernetes, and I contribute upstream to the serving stack I run in production: the vLLM engine, llm-d inference routing, and NVSentinel GPU fault handling.

## Focus

- LLM inference serving: vLLM, request routing with llm-d and Envoy Gateway
- GPU platform on Kubernetes: Dynamic Resource Allocation (DRA), GPU fault detection and remediation
- Systems programming in Rust, including CUDA kernel programming with cuda-rust
